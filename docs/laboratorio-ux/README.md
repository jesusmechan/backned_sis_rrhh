## Cómo entregar (Miro / PDF)

1. **PDF:** abre cada HTML en el navegador → Imprimir → Guardar como PDF.
2. **Miro:** importa los PDF o captura pantallas desde Figma/HTML y pégalas en un board Miro.
3. **FigJam** equivale al formato whiteboard (alternativa a Miro) si el docente lo acepta.
